The diagrams this repository is held to, as files and nothing that runs.

What belongs here is several diagrams of every type that must read and draw, files that must be refused, each opening with the finding it expects and where, and pairs of versions to compare. A test does not belong here, nor a picture drawn of a case, nor anything that says what a case's picture must look like.

Read this pile to find out which diagrams the repository is held to, and where to add one. Change it when a type, a word or a rule is added, or a fault is found that no case shows.
