Writes a diagram's document as HTML that loads and runs nothing: a whole page to open as it is, or one element to embed in another page.

What belongs here is how a document becomes HTML: each node a `<div>` with its style inline, each track CSS keyframes timed as the renderer times them, and the fonts embedded when the page carries them. Where anything goes or how it looks is the document's, not this pile's.

Read this pile to find out what a diagram's page holds and how to embed it. Change it when the page gains or loses something it says, or the way it is embedded changes.
