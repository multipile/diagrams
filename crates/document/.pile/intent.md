The only place that decides where each element of a diagram goes, how it looks and how it moves: its document is complete, so whatever writes it only translates.

What belongs here is one layout for each type, the theme, the fonts the diagrams are set in, the reveal of a diagram and the move from one version to the next, and how a change is drawn: an element added, removed or changed, each as its caller reports it. The document carries each element's key, each line's two keys and the metadata of both, so that a caller can report a change by key and a writer can pass the metadata on. It can say what is drawn differently between two versions, for a caller to decide with. It can say where a file's own choice, such as the order of a tier, draws worse than another it could make, as a hint that never changes what is drawn. Deciding what changed does not belong here, nor reading metadata, nor anything about what a file may say or the syntax of any output.
