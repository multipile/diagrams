Turns a diagram into its complete document: every element placed by its type's layout, painted down to its colours, borders and fonts, and every animation a track of keyframes, so that whatever writes the document only translates it.

What belongs here is where every element goes, one layout for each type, how it looks, in the theme and the fonts the diagrams are set in, how it moves, in a reveal or from one version to the next, and how a change is marked. What a file may say does not belong here, nor the syntax of any output.

Read this pile to find out how a diagram of each type is drawn and animated, and what marks a change. Change it when a type is drawn differently, the look changes, or a document gains or loses a way to move.
