Renders a diagram's document with takumi, with no browser and nothing parsed, to a still or an animated picture.

What belongs here is how a document becomes pixels: each node built as takumi's node with its style set property by property, each frame of an animation posed from the document's tracks, the fonts registered, the scale, and each output format. Where anything goes or how it looks is the document's, not this pile's.

Read this pile to find out which pictures can be made of a document, and how. Change it when takumi changes what it takes, or a format or a way of rendering is added or dropped.
